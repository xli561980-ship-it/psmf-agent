# PSMF Agent：AI 健康管理顾问 PoC

PSMF Agent 是一个面向健康管理、减脂陪伴和营养咨询场景的 AI Agent 原型项目。项目基于 PSMF（Protein Sparing Modified Fast）减脂协议，将专业知识库、用户长期记忆、日常打卡、多渠道触达和安全风险提醒整合在一起，形成一个可演示、可扩展、接近真实业务流程的 AI 健康顾问解决方案。

该项目的核心目标是验证：在健康管理服务中，AI Agent 能否承担基础咨询、个性化建议、连续跟进、饮食记录和风险识别等高频任务，从而降低人工顾问的重复工作量，提高用户响应速度和服务标准化程度。

## 业务背景

健康管理和减脂陪伴类服务通常存在几个典型问题：

- 用户咨询频率高，问题重复度高，人工顾问响应成本较高。
- 减脂方案需要结合体重、体脂、饮食、训练、补剂和身体反馈持续调整。
- 用户长期坚持难度大，需要提醒、复盘和阶段性反馈提升留存。
- 专业健康建议存在风险边界，系统需要识别高风险症状并给出安全提醒。
- 企业如果希望规模化交付个性化服务，需要把专家经验沉淀为可复用的知识库和流程。

PSMF Agent 针对上述问题，构建了一个以 AI Agent 为核心的健康管理 PoC，用于展示大模型在垂直行业服务、私域运营和智能顾问场景中的落地方式。

## 解决方案概述

项目将 PSMF 协议、食物数据库、训练指南、微量元素补充建议和症状风险矩阵整理为本地知识资料，通过 RAG 检索增强大模型回答的专业性和稳定性。用户可以通过网页 Demo、Telegram Bot 或终端入口与 Agent 对话，系统会根据用户档案、历史记录和当前输入生成个性化建议。

Agent 不只是回答单次问题，还会维护用户长期档案，包括体重、体脂、Category、瘦体重估算、蛋白质目标、补剂打卡、训练状态和对话历史。对于胸痛、晕厥、严重乏力、呼吸困难等高风险描述，系统会触发安全提醒，引导用户优先就医或暂停高风险行为。

## 核心能力

- **垂直知识问答**：围绕 PSMF 减脂协议、食物选择、训练安排和补剂建议进行专业问答。
- **RAG 知识增强**：通过本地知识库检索降低大模型幻觉，提高回答与业务资料的一致性。
- **长期用户记忆**：记录用户身体数据、饮食反馈、补剂状态和对话上下文，支持连续服务。
- **日常打卡与复盘**：支持饮食打卡、状态反馈、每日复盘和阶段性总结。
- **多渠道入口**：提供 Streamlit 网页 Demo、Telegram Bot 和终端 CLI，覆盖演示、私域触达和技术验证场景。
- **安全风险识别**：对高风险症状和不适反馈进行识别，避免把医疗风险当作普通减脂建议处理。
- **配置化部署**：通过 `.env.example` 管理模型密钥、Telegram Token、提醒时间和时区等配置。

## 售前价值

- **需求理解**：从健康管理业务中拆解出咨询、跟进、复盘、提醒和风险控制等关键流程。
- **方案设计**：将大模型、RAG、用户记忆、多渠道入口和安全规则组合成完整解决方案。

- **落地意识**：保留环境配置、敏感数据隔离、日志脱敏和模块化入口，为后续产品化或企业集成预留空间。

在真实售前场景中，该 PoC 可以被扩展为健康管理机构、线上营养咨询、私域减脂社群、企业员工健康服务或智能客服系统的行业方案原型。

## 技术架构

```text
用户
  |
  |-- Streamlit Web Demo
  |-- Telegram Bot
  |-- Terminal CLI
        |
        v
GeminiPSMFAgent
  |
  |-- Gemini API：自然语言理解、内容生成、图片信息提取
  |-- RAG System：PSMF 协议、食物库、训练指南、症状矩阵
  |-- Memory Manager：用户档案、每日记录、补剂状态、对话历史
  |-- Safety Rules：高风险症状识别与安全提醒
```

## 功能模块

- `main.py`：终端对话入口，用于快速验证 Agent 能力。
- `telegram_bot.py`：Telegram Bot 入口，用于展示私域触达、主动提醒和持续陪伴能力。
- `app.py`：Streamlit 网页 Demo，用于可视化演示完整用户旅程。
- `psmf_engine.py`：核心 Agent 逻辑，负责对话编排、健康规则、RAG 调用和多模态处理。
- `rag_system.py`：本地知识库索引与检索。
- `memory_manager.py`：用户档案、打卡记录、补剂状态和历史记忆管理。
- `system_prompt.txt`：Agent 角色设定与行为约束。
- `psmf_*.md` / `symptom_diagnostic_matrix.md`：业务知识资料。

## Demo 演示路径

推荐使用 Streamlit 网页版展示完整流程：

1. 输入用户基础情况，例如性别、体重、体脂、目标和当前饮食状态。
2. 展示 Agent 如何判断用户阶段、估算关键指标并给出蛋白质目标。
3. 输入一条饮食或训练打卡，观察 Agent 如何结合历史档案给出反馈。
4. 触发“今日复盘”或 `/summary`，展示长期记忆和结构化复盘能力。
5. 输入高风险症状描述，例如胸痛、晕厥或严重乏力，展示安全提醒机制。
6. 结合业务价值说明该方案如何扩展到企业健康管理、私域运营或智能客服场景。

## 快速开始

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

编辑 `.env`，填写必要配置：

```bash
GEMINI_API_KEY=...
TELEGRAM_BOT_TOKEN=...
```

## 运行方式

终端对话：

```bash
python main.py
```

网页 Demo：

```bash
streamlit run app.py
```

Telegram Bot：

```bash
python telegram_bot.py
```

## 数据与安全

本项目不应提交以下文件：

- `.env` 和任何真实密钥
- `user_profiles.json` 等真实用户健康数据
- `chroma_db/` 本地向量库
- `venv/`、`.venv/`、`__pycache__/` 等生成文件
- 日志、缓存和临时目录

本项目用于 AI 应用原型和行业方案展示，不替代医生、营养师或医疗机构的专业判断。
