# PSMF Agent 简历项目描述

## 1. 简洁版

- 设计并实现面向健康管理 / 减脂陪伴场景的 AI Agent PoC，结合 Gemini、RAG、用户长期记忆、Streamlit Demo 和 Telegram Bot，展示垂直行业 AI 顾问的售前解决方案能力。

## 2. 标准版

- 构建健康管理场景 AI Agent PoC，围绕 PSMF 减脂协议实现用户建档、饮食 / 训练打卡、阶段复盘和安全提醒等完整业务流程。
- 基于 Gemini 和 ChromaDB 搭建 RAG 知识库，将 PSMF 协议、食物数据库、训练指南和症状矩阵用于垂直知识问答。
- 实现本地用户长期记忆，记录体重、体脂、Category、蛋白质目标、补剂状态、历史打卡和对话上下文，支持连续个性化服务。
- 提供 Streamlit Web Demo、Telegram Bot 和 CLI 三种入口，用于客户演示、私域触达和技术验证。

## 3. 售前强化版

- 从健康管理机构、线上营养咨询和私域减脂社群的业务痛点出发，设计 AI 健康顾问 PoC，将高频咨询、用户打卡、阶段复盘和风险提醒整合为可演示解决方案。
- 将 LLM、RAG、长期记忆、多渠道入口和安全规则组合成行业 Agent 架构，并通过“客户痛点 - Agent 能力 - 业务价值”映射说明降本增效、服务标准化和用户留存价值。
- 使用 Streamlit 构建可视化 Demo Storyline，使用 Telegram Bot 展示移动端私域陪伴能力，体现 PoC 快速构建、客户沟通和方案讲解能力。
- 将专业知识资料沉淀为本地 RAG 知识库，结合用户档案和历史打卡生成上下文相关建议，展示从技术实现到行业方案落地的转化能力。
- 在健康类 AI 场景中加入高风险症状识别、免责声明和敏感数据隔离，体现 Presales Engineer 对合规边界、风险控制和真实交付条件的理解。
