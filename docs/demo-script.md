# PSMF Agent 5-8 分钟 Demo 讲解脚本

## 1. 开场介绍

大家好，我今天演示的是一个面向健康管理和减脂陪伴场景的 AI Agent PoC，项目名称是 PSMF Agent。

它不是一个通用聊天机器人，而是围绕一个具体业务流程设计的行业解决方案原型：用户建档、饮食和训练打卡、专业知识问答、阶段复盘、私域触达，以及健康风险识别。

我希望通过这个 Demo 展示两个重点：第一，AI Agent 如何在垂直行业中承接真实业务流程；第二，售前如何把技术能力转化成客户可以理解的业务价值。

## 2. 客户痛点说明

这个场景的目标客户可以是健康管理机构、线上营养咨询服务商、私域减脂社群，或者企业员工健康管理平台。

他们通常会遇到几个问题：

第一，人工顾问每天要重复回答大量基础问题，比如怎么吃、怎么练、体重波动怎么办，响应成本很高。

第二，减脂不是一次性咨询，而是一个持续服务过程，用户需要长期打卡、提醒和复盘，否则很容易中断。

第三，普通 chatbot 缺少上下文，无法持续记住用户的体重、体脂、饮食历史和阶段目标。

第四，健康建议有安全边界。比如用户出现胸痛、晕厥、呼吸困难或严重乏力，系统不能继续当作普通减脂问题处理。

所以这个 PoC 的目标，就是用 AI Agent 验证能否把专家知识、用户记忆和服务流程结合起来，形成一个可规模化的 AI 健康顾问。

## 3. 方案架构说明

整体架构分为四层。

第一层是用户入口，包括 Streamlit Web Demo、Telegram Bot 和 CLI。Web 适合客户现场演示，Telegram 适合展示私域触达和持续陪伴，CLI 用于快速技术验证。

第二层是 Agent 核心，也就是 `GeminiPSMFAgent`。它负责对话编排、信息抽取、规则判断、RAG 检索、长期记忆读取和回复生成。

第三层是数据和知识层，包括 PSMF 协议、食物数据库、训练指南、症状风险矩阵、用户档案和历史打卡记录。

第四层是安全层，主要负责识别高风险症状、输出安全提醒，并在必要时建议用户停止当前行为、寻求专业人员或医疗机构帮助。

## 4. Demo 操作流程

接下来我用 Streamlit 版本演示完整用户旅程。

第一步，我输入一个新用户的基础信息。例如：我是男性，体重 85 公斤，体脂 25%，最近想开始 PSMF 减脂，今天第一天，精神还可以。

这里可以看到，Agent 会先做基础建档，识别体重、体脂和目标，并估算用户当前阶段。它不是直接给泛泛建议，而是围绕 PSMF 协议给出结构化起步建议。

第二步，我输入一条饮食打卡。例如：今天吃了鸡胸肉、鸡蛋和一些蔬菜，感觉有点饿。

这时 Agent 会结合用户档案和当前打卡内容，给出蛋白质、饱腹感、补剂或饮食结构方面的反馈。这体现的是长期服务能力，而不是单轮问答。

第三步，我触发“今日复盘”或输入 `/summary`。

这里展示的是复盘能力：系统会读取用户历史记录，整理当天状态、关键风险、执行情况和下一步建议。对客户来说，这可以对应到用户运营中的每日总结、自动陪伴和留存提升。

第四步，我输入一个高风险症状，比如：今天胸口有点痛，还有点喘不上气。

这时 Agent 应该触发安全提醒，而不是继续鼓励用户减脂或训练。这个环节体现的是健康类 AI 应用必须具备的风险边界意识。

第五步，如果客户关心渠道落地，我会切到 Telegram Bot，说明同一套 Agent 核心也可以用于私域社群、移动端提醒和长期陪伴。

## 5. 关键亮点解释

这个项目有几个关键亮点。

第一，它把专家知识沉淀成 RAG 知识库，而不是只依赖模型自由发挥。

第二，它有用户长期记忆，可以支持连续跟进和个性化反馈。

第三，它有多渠道入口，能同时覆盖演示、私域运营和技术验证。

第四，它把业务规则和大模型结合起来，例如 Category 判断、蛋白质目标、打卡复盘和风险提醒。

第五，它在健康场景中强调安全边界，体现了 PoC 到真实落地之间必须考虑的合规和风险意识。

## 6. 商业价值总结

从业务价值看，这个方案可以帮助客户降低人工顾问的重复咨询成本，提高用户响应速度和服务一致性。

同时，它可以通过每日打卡、复盘和提醒提升用户留存，把原本依赖个人经验的服务流程沉淀为可复制的知识库和 Agent 工作流。

对售前来说，这类 PoC 的价值不是展示“我会调用大模型”，而是展示“我能把客户痛点拆解成解决方案，并用一个可演示 Demo 证明它有业务价值”。

## 7. 可扩展方向

后续可以扩展几个方向。

第一，接入企业 CRM、会员系统或客服工单系统，让 AI 建议和客户运营数据打通。

第二，替换为客户自己的知识库，比如营养课程、产品手册、服务 SOP 或医疗科普资料。

第三，增加顾问工作台，让 AI 先生成建议，再由人工顾问审核和接管高风险用户。

第四，扩展到企业微信、小程序、App 或客服系统，适配真实客户的渠道环境。

第五，增加数据看板，追踪打卡率、留存率、风险提醒次数和服务质量。

## 8. 结束话术

总结一下，PSMF Agent 是一个围绕健康管理业务流程构建的 AI Agent PoC。它展示了从客户痛点、方案架构、Demo Storyline 到业务价值映射的完整售前思路。

这个项目最能体现的是：我不仅能理解大模型和 RAG 的技术实现，也能把它们包装成客户听得懂、看得见、能评估的行业解决方案。
